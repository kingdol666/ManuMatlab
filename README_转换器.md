# Markdown转PDF转换器

这是一个带图形用户界面的Markdown转PDF转换工具，支持多种转换方法，操作简单直观。

## 功能特点

- 🖥️ 直观的图形用户界面
- 📄 支持标准Markdown语法，包括表格和代码块
- 🔄 多种转换方法可选（HTML输出、PDFkit、WeasyPrint）
- 📊 实时进度显示和状态反馈
- 📝 详细的转换日志
- 🎨 美观的PDF输出样式，支持中文字体

## 安装与运行

### 方法一：使用启动脚本（推荐）

1. 双击运行 `启动转换器.bat`
2. 脚本会自动检查并安装必要的依赖
3. 启动应用程序

### 方法二：手动安装

1. 确保已安装Python 3.7或更高版本
2. 安装依赖：
   ```
   pip install -r requirements_gui.txt
   ```
3. 运行应用：
   ```
   python md_to_pdf_gui.py
   ```

## 使用方法

1. **选择Markdown文件**：点击"选择Markdown文件"按钮，选择要转换的.md文件
2. **设置输出路径**：点击"设置输出路径"按钮，选择PDF文件的保存位置
3. **选择转换方法**：
   - **HTML输出**：生成HTML文件，可在浏览器中打开并打印为PDF（无需额外依赖）
   - **PDFkit**：直接生成PDF（需要安装wkhtmltopdf）
   - **WeasyPrint**：直接生成PDF（需要安装WeasyPrint）
4. **开始转换**：点击"开始转换"按钮，等待转换完成
5. **查看结果**：转换完成后可选择直接打开生成的文件

## 转换方法说明

### HTML输出（推荐新手使用）
- 无需安装额外依赖
- 生成HTML文件，可在浏览器中打开
- 使用浏览器的打印功能保存为PDF
- 兼容性最好，输出质量高

### PDFkit
- 需要安装wkhtmltopdf：https://wkhtmltopdf.org/downloads.html
- 直接生成PDF文件
- 转换速度快，输出质量好

### WeasyPrint
- 需要安装WeasyPrint及其系统依赖
- 直接生成PDF文件
- 支持现代CSS特性，输出质量高

## 注意事项

1. 转换大文件时可能需要一些时间，请耐心等待
2. 确保Markdown文件使用UTF-8编码
3. 如遇到中文字体问题，请确保系统已安装中文字体
4. 使用PDFkit或WeasyPrint方法前，请确保已安装相应的依赖

## 系统要求

- Windows 7/8/10/11
- Python 3.7或更高版本
- 至少100MB可用磁盘空间

## 故障排除

### 问题：启动失败
- 检查Python是否正确安装
- 确保所有依赖包已安装

### 问题：转换失败
- 检查Markdown文件是否存在
- 确保输出路径有写入权限
- 尝试使用不同的转换方法

### 问题：PDF中文显示异常
- 确保系统已安装中文字体
- 尝试使用HTML输出方法，在浏览器中打印为PDF
